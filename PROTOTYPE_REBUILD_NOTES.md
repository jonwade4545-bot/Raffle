# Raffle prototype rebuild

This rebuild replaces the simplified home screen with the richer dark/purple mobile interface from the approved concept screens.

Included in the prototype:
- Marketplace-style Home with search, categories, Trending Now, Ending Soon and New This Week
- Bottom navigation: Home, Discover, Create, My Entries, Profile
- Promotion details screen with 100-entry progress, free-entry CTA, prize details, fulfillment and rules
- Discover grid
- My Entries dashboard
- Profile dashboard and seller quick access
- Seller Dashboard
- Existing Create Promotion, authentication, Supabase, submissions/admin and settings code remains in the project

The sample product content is prototype/demo data so the interface can be evaluated before backend content is complete.
